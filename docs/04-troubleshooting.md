# 04. 診断ツリー: Ghe が鳴らない

```
[TEST 0] 左手を完全に離し、右手指 1 本でマイダーンを軽打して即離す
  ├─ 1 秒以上鳴る → 楽器正常。左手の問題 → TEST 1 へ
  └─ 鳴らない → 楽器/環境の問題 → 4.2 へ

[TEST 1] 圧をかけてピッチを変えながら打つ
  ├─ 尾が伸びる → 打点/インパルス正常。手の「据わり」の問題
  │    → 圧を減らしつつ手の硬さを保つ。ゼロ圧を目指さない
  └─ それでも伸びない → TEST 2 へ

[TEST 2] 出ている音の種類を判定
  ├─ 「パタ/ボフ」無音程 → 指が寝て Ka 化。指を 90 度に立て直す
  ├─ 有音程だが短い → 打った指が面に残留。離す速度を上げる
  └─ 高くて細い音 → 打点がスィヤヒ上かキナール上。マイダーンへ移す

[TEST 3] 単発は鳴るが連打で閉じる
  └─ 次打準備で指が面に戻っている。指を浮かせて待機、交互指に変更

[TEST 4] 全部やっても不明
  └─ 左手を横から動画撮影 → 他人 (オンライン可) に 30 秒見てもらう
```

## 4.2 楽器/環境チェックリスト

- [ ] 湿度: 日本の夏は皮が湿気を吸って重くなる。除湿部屋に半日 / 演奏前に温める
- [ ] 張力: 低くても明確な音程が出るのが正常。「ボフッ」で音程不明なら緩すぎ。バヤンはガッター (木駒) の抜き差し・上下で調整
- [ ] スィヤヒ: ひび割れ網は正常 (工法)。ただし縁の浮き・剥がれは NG
- [ ] 台座リング上で安定しているか。ぐらつくと打点がずれる

## 4.3 撮影チェック観点 (動画セルフレビュー用)

1. 手首はマイダーンの中に着地しているか。打の間動いていないか
2. 指の角度は 90 度か。第一関節の先で当たっているか
3. 打点はスィヤヒとキナールの中間か
4. 打後、指は何 ms で離れているか (スロー再生)
5. 連打間、指は面上で待機できているか
