# 07. 未解決事項 (issue 候補)

GitHub issue に切り出す際のテンプレ: 背景 / 仮説 / 検証方法 / 完了条件

## Q1. ベースライン圧の量

- 背景: 「軽い圧」の定量値がどのソースにもない
- 検証: 圧を 0 から段階的に増やしながら録音し、サステイン長 (RMS decay) を圧レベルごとに測る
- 完了条件: 自分の楽器での最適圧レンジが分かる

## Q2. 手首位置の許容範囲

- 背景: NCERT「マイダーンの中」/ TaalGyan「スィヤヒ縁のすぐ外」で幅がある
- 検証: 手首位置を 1 cm 刻みで動かして録音比較
- 完了条件: 位置 vs 音色のマップ

## Q3. Ge (人差し指) と Ghe (中指) の音色差

- 背景: Sangtar の区別が自分の楽器で再現できるか未確認
- 検証: 同一打点・同一圧で指だけ変えて録音、スペクトル比較 (Python + librosa で可)

## Q4. 湿度と減衰時間の関係

- 背景: 日本の夏の湿度影響を定量化したい
- 検証: 湿度計 + 同一打の録音を数週間分ログ
- 備考: DWH 的に貯めるなら日次 CSV → 集計。過剰装備注意
