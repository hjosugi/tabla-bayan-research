# 05. 腕・手首の負傷予防

## 5.1 因果構造

```
指残留で減衰 → 「力不足」と誤解釈 → 腕から強打 → それでも減衰 → さらに強打 → 過負荷
```

- さらに: 据えるべき手首を浮かせて支え続けると、静的保持だけで前腕が疲労する
- 正しい Ghe は指の跳ね返しのみ。腕の疲労はフォーム誤りのセンサーとして使う

## 5.2 overuse injury の基礎知識

- 生体組織 (筋・腱・靭帯) が物理的限界を超えると微小外傷 (微細断裂+出血+腫脹)
- 音楽家の「腱炎」は腱そのものより腱に付く筋が痛むことが多い
- 手首では De Quervain (親指側) / ECU 腱炎 (小指側) が代表的

## 5.3 運用ルール

- 練習は ~45 分で区切り、最低 5 分休む。難所の連続反復は 5 分以内
- 痛み (だるさではなく痛み) が出たら即中止
- 数日引かない痛み・腫れ・握力低下 → 整形外科
- 応急は RICE (安静・冷却・圧迫・挙上)。20 分冷却
- 強度は段階的に上げる。突然の練習量スパイクを避ける

## 5.4 ドラマーとしての類推

- スティックを握り込んでリバウンドを殺すと腕が死ぬのと同型
- フリーストロークのリバウンド感覚を指に移植する。押し付けたスネアは鳴らない
