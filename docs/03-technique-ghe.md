# 03. Ghe 奏法: 確定事項と流派差

## 3.1 ソース間で一致している事項 (確定)

1. 手首 (मणिबंध, 付け根) は **マイダーンの中の皮の上に置く**。浮かせない
2. スィヤヒの偏心は手首の席を空けるための設計 (NCERT 第 2 章に明記)
3. 指は 90 度に曲げ、先端で打つ。「蛇のフード (সাপের ফণার মত)」のアーチ
4. 打点はスィヤヒとキナールの間 (マイダーン/ラヴ)。スィヤヒ上を叩かない
5. 掌圧でピッチベンドする。圧は奏法の一部であり悪ではない
6. 打った指は即座に上げる。手首は動かさない

## 3.2 音の分類 (誤爆診断用)

| ボル | 打ち方 | 音 |
|---|---|---|
| Ghe / Ge | 手首据え + 立てた指先で打つ | 低い有音程音。開音 |
| Ka / Ke | 掌〜4 指を平らに落とす。指先が縁に触れる | 無音程のスラップ。閉音 |
| Ghissa | 打後に掌の付け根を中央方向へ滑らせる | 共鳴が徐々に閉じるベンド |

指の角度だけで Ghe と Ka が分かれる。「まったく違う音」の第一容疑者は意図しない Ka 化。

## 3.3 指の使い分け (流派・教本で割れる)

| ソース | Ge | Ghe | 手首位置 |
|---|---|---|---|
| NCERT (Hindi 公式教科書) | - | 中指+薬指を揃える | マイダーンの中 |
| Sangtar (奏者ブログ) | 人差し指の先 | 中指。Ge より圧強め | 手の甲側を面に置く |
| TaalGyan | - | - | スィヤヒの縁のすぐ外 |
| Sachitra Tabla Shiksha (Bengali, 1900年代) | - | 中指先端で反対側を打つ | 掌をガブの後ろ |

割れているのは細部のみ。3.1 の骨格は全ソース一致。

## 3.4 流派 (gharana) について

- Courtney: 現代ではガラーナー厳守は職業的に不利。大別すると Delhi 系 (Delhi, Ajrada) と Purbi 系 (Lucknow, Farrukhabad, Benares) の 2 哲学
- モジュレーション (左手のベンド) は「多くの時間を割くべき」領域で、具体的推奨は文字化されていない = 口伝領域
- Zakir Hussain は圧+スライドだけでメロディを演奏できたレベル。上限は非常に高い

## 3.5 練習手順 (現状の処方)

1. 手首をマイダーンに据える。軽い圧 OK
2. 中指 (or 人差し指) 90 度、スィヤヒ奥側とキナールの間を打つ
3. 指だけ即座に上げる。手首固定
4. 1 発打って 2 秒静止して聴く。60 BPM から
5. 圧を連続的に増減して尾が生きたままピッチが動くか確認 (これができれば境界制御を獲得)
6. 連打は人差し指・中指の交互。指は面上 2-3 cm で待機

チェック指標:
- 腕が疲れない (疲労 = フォーム誤りのセンサー)
- 尾が切れる瞬間があれば、その直前の指/手の動きが犯人
