# 01. 打面の部位名

多言語対照。文献検索時の検索語として使う。

| 日本語表記 | 英語転写 | ヒンディー語 | ベンガル語 | 意味 |
|---|---|---|---|---|
| プーリー | puri / puddi | पूड़ी | পুরি | 打面全体 (山羊皮) |
| スィヤヒ | syahi / gab | स्याही | গাব | 中央の黒い錬り物。鉄粉+糊。バヤンでは偏心 |
| マイダーン | maidan / lav | मैदान / लव | ময়দান | スィヤヒとキナールの間の主共鳴部 |
| キナール | kinar / chat | किनार / चाँटी | কিনার | 縁の環状部。膜に密着せず高次モードを抑える設計 |
| ガジャラー | gajara | गजरा | - | 縁の編み込み。チューニング時にハンマーで叩く |
| ガッター | gatta | - | - | 胴と革紐の間の木駒。バヤンの張力調整に使う |
| バヤン別名 | bayan / duggi / banya | बायाँ / डग्गा | বাঁয়া | 「ダッガー」表記は NCERT 系で頻出。検索語として重要 |

## 検索語メモ

- Hindi で奏法を探すなら「डग्गा」「बायाँ」+「घे / गे」+「कलाई」(手首)
- Bengali なら「বাঁয়া」+「ঘে」
- 学術系は英語で "bayan" "composite membrane" "syahi" "eccentric loading"
