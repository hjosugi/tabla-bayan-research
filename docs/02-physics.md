# 02. 物理: 膜振動と減衰

## 2.1 減衰の 4 因子モデル

接触による減衰量の近似:

```
damping ≒ 接触面積 × その点での膜の変位 × 接触物の損失係数 × 接触時間
```

- 変位項が支配的。基音モードは中央付近で最大、縁でほぼゼロ
- 損失係数: 脱力した手 (粘弾性体) は高損失 = 優秀なダンパー。硬く据えた手は低損失 = 境界として振る舞い反射する
- 「触っているか」ではなく「どこを・どの硬さで・いつまで」が問題

## 2.2 手首 = 可動境界モデル

- マイダーンに据えた手首は膜を 2 セグメントに分割する
- 鳴るのは手首より奥のセグメント。手前は死んでいてよい
- 圧を増やす → 有効セグメント縮小 + 張力増 → ピッチ上昇 (トーキングドラムと同原理)
- 実測に基づく確定事項: Ghe は全ボル中唯一の連続可変音。打つ瞬間の掌圧が音程を作る (Chordia/CCRMA)

## 2.3 スィヤヒの音響 (研究史)

- Raman (1920, Nature): タブラの倍音は 1:2:3:4:5 の完全調和列。膜楽器では例外的。最初の 5 共鳴は 9 個の固有モードに対応
- Raman の指摘: キナールは膜と完全密着しておらず、ピッチではなく高次非調和モードの抑制に働く設計要素
- Ramakrishna & Sondhi (1954): 面密度に段差を持つ複合膜として理想化。半径比 0.4・密度比 3.125 で第 9 モードまでほぼ調和。縮退モード多数
- バヤンのスィヤヒは偏心 → モード縮退を破り非対称振動パターン。ダーヤー (同心) とは別物。手首の効きは角度依存
- 空気負荷: ダーヤーでは調和性の微調整程度、バヤンでは調和性を大きく改善し、音楽的に重要なモードの減衰時間を延長 (Khula bols 論文)
- スィヤヒ表面のひび割れ網 (reticulum of cracks) は付加質量の剛性を下げるための工法。層を重ねて乾かし石で磨く

## 2.4 症状への適用

| 観察 | 物理的解釈 |
|---|---|
| 音程を変えながら叩くと尾が伸びる | 圧をかけた手 = 硬い境界。吸収せず反射。楽器・打点・インパルスは正常と確定 |
| 普通に叩くと伸びない | 手が柔らかい (据わっていない/脱力) か、指が面に残留 |
| 連打で open にならない | 次打準備で指が面に戻り毎回ミュート |
| まったく違う音がする | 指が寝て Ka 化、または手首不在で境界条件が別物 |

## 2.5 基音の目安

- バヤン基音 ~80-120 Hz → 1 周期 ~10 ms
- 指の接触 3 ms なら「叩いて逃げた」、40 ms 残ると 4 周期分を吸収
- チューニング慣習: バヤンは下オクターブの Ga/Pa/Ma あたり (フォーラム情報、要検証)
